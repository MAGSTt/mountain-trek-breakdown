研究对象

《Unravel》第一部 · 第四关 Mountain Trek。 玩家操作毛线精灵 Yarny 穿越山林、洞穴和水域，通过毛线连接、物体运输与环境互动抵达终点。本案围绕关卡设计展开，剧情只保留与玩法节奏有关的说明。

项目 内容
分析范围 从树枝出生点到毛线蝴蝶奖励，以及通关后的相册收束
结构规模 10 个体验阶段 B00–B09，15 个局部问题，5 枚隐藏纽扣
核心动作 移动、跳跃、套索、系结／解结、攀爬、摆荡、推拉物体
分析重点 规则如何被看见、能力如何递进、空间如何限制解法、压力如何切换
核心材料 原 XMind 脑图、实机标注图、用户剪辑的示范视频与操作确认
网络材料 官方主题介绍及第三方关卡攻略，用于交叉核对，来源附在本节末尾
不展开的内容 全游戏剧情考据、人物身份推定、逐张照片配对、引擎实现

拆解单位与证据

B（Beat）按一段体验在全关中的功能划分；P（Puzzle）按“局面受阻 → 玩家解决 → 局面改变”划分。套索、跳跃等是问题的操作属性，不单独切成一道谜题。纽扣、补给和回忆是附着在路线上的标记。

事实与解释分别保留来源：用户确认／实机标注说明实际行为与位置；原记录保留脑图中的镜头、音乐和风险观察；资料补充注明外部来源；分析解释设计作用，不能当作开发者原话或玩家测试结果。

视频按要求原样嵌入，未抽帧、转码或另行分析。文字依据原记录、图片标注和用户说明；未测量的数据保持空白。

01_研究问题

本案尝试回答五个问题。每个问题都对应关卡证据，以及目前能得出的结论范围。

研究问题 重点观察 对应证据 目前结论
已有基础能力如何撑起一整关的变化？ 操作相近时，空间、时限和目标如何变化 B01 复习、B05 组合、B06 追逐、B07 多层空间 变化主要来自使用条件与组合关系，而非持续添加新按钮
玩家怎样从看见环境现象，转为主动利用规则？ 示范是否显示原因、玩家是否有复现机会 B02–B03 孢子链；B08 鸟压枝与牵拉重物 存在“演示—再次提示—主动应用”的结构；实际理解率仍需首次游玩测试
为什么 B07 仍然难，却能承接追逐后的释放？ 认知负荷与即时威胁是否分别变化 B06 追逐视频、B07 主路与错误路线图 决策时间变长、追击解除，认知复杂度仍然保留
隐藏收集是否只是把奖励放远一点？ 是否改变观察方向、道具状态或空间阅读方式 五枚纽扣，尤其 C03 配重、C04 运石、C05 回看 收集分别测试下探、上看、状态切换、前置推理和事件后回看
关卡怎样限制错误解法，同时维持可理解性？ 限制是否可感知，失败是否提供信息 落石封路、毛线长度、跳跃高度、木桶移动边界 限制能组织解题顺序；可读性与失败公平性不能仅凭成功路线定案

研究边界： 当前材料足以分析关卡结构和操作因果，不足以声称“新手一定能理解”“该段平均失败几次”或“所有玩家都会感到放松”。这些需要实测。

02_整关结论

核心结论

Mountain Trek 通过轮换压力类型，反复使用同一套毛线与物理能力；收藏支路再为熟悉主线的玩家增加不同层次的观察要求。

结论 关卡证据 设计意义
递进发生在能力的使用条件上 B01 慢速复习 → B05 多步组合 → B06 限时执行 → B07 空间统筹 让玩家持续调用既有能力，降低新规则负担
演示与主动应用相互连接 孢子从遭遇现象变成取船工具；鸟压枝后，玩家通过毛线牵拉重物复现 知道规则与能够按需使用规则之间，有明确的实践环节
动作高潮后改变挑战类型 B06 追逐结束后进入 B07 多层谜题 释放紧迫感，同时保留内容密度
环境变化服务不止一个目标 杠杆两种配重；木料先造成危险、再搭出通路并露出收藏空间 同一套场景关系可以产生多个局部目标
收藏拓展“怎样看空间” C02 看上方、C03 换状态、C04 找前置、C05 回头看 额外探索不完全依赖距离或遮挡

需要保留的判断

本关的张弛并不是每段越来越难。鱼船与滑翔都带来运动方式变化，但不能因为画面速度快就认定操作复杂；B07 操作未必最难，却有较高的路径和资源推理要求。

叙事作为第二条积累线存在：走近人物影像后自动呈现、化为白光并被收集，通关后照片入册。它解释旅程留下什么，但不是本案的主要篇幅。

最值得继续验证的是：孢子因果是否足够清楚、追逐的危险是否提前可读、B07 毛线不足是否能帮助玩家修正路线，以及 C05 是否给出了足够的回看理由。

04_机制递进表

机制／能力 低压力接触与提示 发展与组合 后续检验或变化 递进轴
套索与摆荡 B01 连接点推进 B02 下滑与跨水；B05 系结后下降接下一点 B06 追逐中连续执行 可决策时间、衔接次数、失败后果
系结成桥／弹跳 B01 高处目标与物体转移 B03 隐藏支路；B05 重物运输 B07 运石支线与毛线资源管理 从局部可达性到运输和整体路线
物体推拉 B01 支撑物改变倒木 B05 重物运输＋杠杆配重 B07 木桶垫脚、石头运输；B08 重物牵枝 物体的中间位置和最终位置都参与解题
攀爬根系 B01 发光表面提示 B02/B03 高处通行 B06 追逐末尾脱离威胁；B07 多层路径 从单动作复习到关键出口动作
孢子与敌人关系 B02 首次遭遇中的环境事件 B03 接触蘑菇后的重复暗示 B03 主动踩踏驱退、取得船 被动观察转为主动利用；不虚构后续孢子考试
动态物体改变道路 B01 倒木；B05 杠杆反馈 B08 鸟压枝、重物牵拉 B08 木料滚落：威胁转为通路 同一对象在过程中的功能变化
借助移动载体 B04 鱼船 B08 塑料袋滑翔 两者均需持续按住发射毛线；滑翔不能左右控制 熟悉输入的情境变化，不等同新增可控飞行能力
空间探索 C01 下探 C02 上方支路、C03 配重切换 C04 前置运输链、C05 事件后回看 观察方向、状态理解和路径规划

“复习”是本关中的功能，不意味着这些能力在全游戏首次出现。不同机制的成熟程度不一致，不应硬套每条机制都有完整的四阶段教学。

05_节奏曲线

● 认知负荷┄ 操作负荷● 即时威胁

分开看三种负荷

  • 认知负荷： 需要同时理解多少关系，解法是否需要多步规划。
  • 操作负荷： 跳跃、套索、摆荡与输入衔接是否要求稳定执行。
  • 即时威胁： 玩家能否停下来观察，还是必须立即作出动作。

曲线采用相对等级，横轴以阶段等距排列，不代表各阶段实际时长，也不是玩家实测评分。B05、B08 内部存在短时起伏，单个阶段点只用于概括。

关键转折

转折 变化 对体验的作用
B01 → B02 下滑速度、落石与落水风险进入 低压复习转向反应与危险判断
B02 → B03 敌人仍在，但孢子可以主动使用 在威胁中恢复一定控制感
B03 → B04 取船解谜切入移动载体事件 从布置与接近转到持续输入和速度体验
B05 → B06 相近动作进入持续追逐 主要抬升执行压力，不依赖复杂新解法
B06 → B07 追击解除，多层空间问题开始 即时威胁下降，认知负荷上升
B07 → B08 → B09 出洞、短机关、局部危险，再结束挑战 通过开阔场景与短循环逐步收束

补给与存档的分布逻辑

原脑图记录补给／存档常出现在落水、敌人遭遇、鱼船、追逐、大型谜题与短机关的前后。其设计作用可以理解为“准备 → 挑战 → 安全确认”，但不同段落的前后点可能重合，不能将其直接相加得到数量。

原记录位置 对恢复的意义 仍待确认
B01 多次补给 支持基础复习与场景交替 精确数量、是否都可复活
B02/B03 危险或敌人前后 缩短认识危险和尝试规则的回退距离 谜题物体与孢子状态如何重置

12_可迁移原则

原则 适用条件 本关例子 迁移时需注意
先展示因果，再要求主动复现 规则能通过环境状态被看见 孢子、鸟压枝 示范中的关键原因不能被更强的危险或镜头运动遮住
用约束变化增加深度 玩家已经基本掌握核心动作 同一套索动作在复习、组合和追逐中复用 同时增加距离、时限、遮挡会难以判断失败原因

叙事留存可以位于动作之外 不希望回忆承担能力成长功能 影像收集、照片入册 不强制每道题插入演出，避免破坏动作节奏

迁移单位是机制关系与使用条件，而不是照搬“放一只鸟”“放五枚纽扣”或相同场景外观。

13_如果重做

以下是基于现有材料提出的改版假设，不是对原作功能的描述。优先保留 B00–B09 的张弛、核心毛线操作、孢子主动应用、B07 空间问题及五种收藏要求；先解决信息表达与恢复成本，再考虑改结构。

优先验证的改动

优先级 修改位置 提议 预期收益 代价与边界 验证标准
P1 B02 首次孢子演示 微调镜头与事件节拍，让蘑菇破坏、孢子出现、动物反应在同一注意窗口内可见 因果更容易被记住并迁移到 B03 避免长时间锁镜头；不在追逐中强行夺走操作 初次玩家能够解释原因，并尝试踩踏而非反复冲撞
P1 B06 追逐 保留晃动气氛，提供较低晃动选项；确认下一结点在起跳前可辨认 让主要挑战落在执行而非看不清 不自动放宽全部时机窗口 记录不可见导致的失败占比，与动作失误分开比较
P1 B07 毛线不足 检查绷紧反馈、来源方向与多余系结是否可读，必要时加强局部提示 帮助玩家修正路径和理解占线 不直接画出正确路径，保留空间推理 玩家能说出“为什么不足”，并产生不同于重复尝试的下一步
P2 B08 木料与 C05 在木料稳定后短暂保留空仓可见性，用自然空隙和光线提示空间改变 增加回看机会 不直接把纽扣高亮成必捡目标 玩家注意到空仓，但仍需要主动选择回看
P2 鱼船／塑料袋 若测试证明持续输入形成负担，增加可选的保持连接方式 降低无意松手的输入负担 默认体验与规则说明要一致，不替玩家进行方向或解谜决策 已理解规则的玩家因误松手失败减少，仍能理解连接状态

暂不改动的部分

不因攻略提供替代解法就强制封死 B01 的弹跳路线；不把 B07 简化成单向走廊；不为所有回忆补独立过场；不为了让收藏“越来越难”而把五枚纽扣拉成机械的难度阶梯。

小范围验证流程

先用现有版本观察首次游玩 → 记录具体误读、失败原因与重试耗时 → 每次只改一个关键变量 → 对照新的行为记录 → 保留有证据支持的变化。

需要补录的数据包括首次解出时间、无效重复次数、连接点可见性、失败后重做内容与收藏发现路径。此处不预设样本结果或虚构改善百分比。

07_详细关卡分析 / B00

环境与方向建立

先让玩家知道往哪里走，再让玩家决定怎样过去。

认知低操作低即时威胁低

体验边界： 从进入山林并取得角色控制，到面对第一组需要操作解决的路线阻碍。此处没有必要为了凑谜题而设 P。

角色初始朝向右下，左侧被树干阻挡，向右构成自然推进方向。开阔山林、偏暖视觉和舒缓音乐先建立一个相对轻松的基准，随后洞穴的阴暗、收窄与威胁才有比较对象。

玩家行为： 观察 → 下到可行走区域 → 向右移动 → 接近第一处阻碍。成功反馈就是路径持续可见、角色能够推进。原记录未标出本段补给或收集，不据此断言本段一定没有回忆。

设计作用： 先减少方向选择，再引入操作选择。玩家尚未被要求同时理解地图、工具和敌人规则。

07_详细关卡分析 / B01

基础能力低风险复习

用低压力的小问题，重新唤起毛线与物体操作。

认知较低操作较低即时威胁低

体验边界： 第一组路线阻碍 → 林地与短洞穴交替 → 长洞穴入口。整体目标是把已有能力重新放回玩家手里；“复习”是本关功能判断，不意味着这些能力在全游戏首次出现。

B01-P01

抓取、牵拉与套索推进

  • 受阻局面： 目标位置超出直接跳跃可达范围，环境中的支撑物或连接点提供其他可能。
  • 解决过程： 观察物体与地形的支撑关系 → 抓取／牵拉相关物体 → 利用地形变化与上方连接点推进。
  • 状态改变： 原本不可直接到达的路径变得可达。
  • 引导： 高度不足排除纯跳跃，物体位置与连接点提供操作对象。
  • 失败成本： 原记录未见明显死亡压力；无效尝试主要表现为不能抵达目标。
  • 设计作用： 重新建立“环境可以改变”的意识，不只复习按键。

【资料补充】开场可通过移走支撑石改变倒木状态。此细节支持“先改变环境再前进”的解题链。Jeuxvideo 关卡图文攻略

B01-P02

系结结构与物体转移

  • 受阻局面： 玩家需要取得更高落点，单纯跳跃不足；相邻连接点与可移动物体处于同一局部空间。
  • 原记录路线： 连接两点 → 建立运送通路 → 转移物体至垫脚位置 → 跳上目标点。
  • 状态改变： 系结先改变物体的运输条件，物体再改变角色的可达高度。
  • 引导： 靠近的结点提示连接关系，目标高度提示需要额外手段。
  • 失败成本： 主要是物体位置或路线不正确后进行调整。
  • 设计作用： 把“系结”和“搬运”组成有目的的操作链。

【资料补充】攻略还记录了直接使用弹跳绳到达高处的路线。因此这里不能写成“强制要求所有玩家搬运物体”，应称为脑图记录的一种解法。TrueAchievements：开场替代解法

B01-P03

短洞穴通行与攀爬

  • 受阻局面： 路线进入短洞穴，需要从低处向上通过。
  • 解决过程： 识别表面带亮光的可攀爬藤蔓／根系 → 攀上高处 → 返回林地推进。
  • 状态改变： 从受限低处进入上层通路。
  • 引导： 可攀爬表面与一般背景有视觉差别。
  • 设计作用： 在空间收窄、照明变化中复习垂直移动。

过渡补充。 攻略提及进入相邻洞段前需要拉倒挡路木头，并提示靠得过近可能被砸。本文把它暂记为本阶段过渡机关，精确归属待截图确认。这也意味着脑图中“唯一死亡点且无关操作”的说法应改成“整体低风险，局部动态物体仍可能造成死亡”。TrueAchievements：挡路木头

视听与补给： 原记录中山林主题延续；林地与短洞穴反复过渡，至少两处补给。进入长洞穴时，明亮开阔向阴暗潮湿的变化承担阶段收束。

B02-P01

下滑、落石与水域推进

  • 受阻局面： 快速下滑把玩家送入需要摆荡通过的地段；可踩落石并非长期稳定平台。

  • 状态改变： 从可慢慢试的地面移动转为需要留意时机的跨越。

  • 失败： 落水。原记录还列了被敌人抓住，但其是否发生在 P01 范围内待边界核对。

C01 标记： 原记录称目标显眼且靠近主路径，获取位置刁钻，考绳长和摆荡控制。保留“主路附近的操作型可选收集”，不将“靠近主路”写成“必定会拿到”。可见程度会受到镜头与下滑时机影响，待截图确认。

  • 失败： 回撤不及时被抓住。
  • 设计作用： 用短暂失控迫使玩家重新看待同一个场景，再通过路径开放恢复控制感。

证据边界： 脑图明确记录“孢子呛退”。外部攻略对首次停止追击也存在“光照边界”等不同措辞，因此首次退缩的精确因果不以攻略文字定案。更稳妥的表述是“破坏蘑菇、动物停追、上路开放共同构成演示；孢子驱退在 B03 被玩家主动应用”。动物统一沿用你的“土拨鼠”称呼，并注明为追逐啮齿动物；网络有 lemming、gopher 等叫法，暂不认定物种。Gamepressure：首次遭遇及后续蘑菇

综合解谜与操作组合

  • 引导： 玩家站上右侧导致其下沉，直接展示“重量会改变姿态”。
  • 失败成本： 原记录未见死亡风险，主要是配重错误后重新调整。
  • 设计作用： 把物体运输、重量关系、路线判断串成多步问题；思考重点从能否触发物体转到物体应该停在哪里。

高压追逐与威胁收束

熟悉动作遇上时间压力：考验的是迅速、连续地执行。

认知较低操作高即时威胁高
B06-P01

逃离追逐动物

体验边界： 威胁正式恢复追击 → 连续跨水 → 末段攀爬 → 动物坠落、追逐解除。

  • 受阻局面： 不仅要过水，还必须赶在敌人追上之前完成。
  • 解决过程： 向右逃跑 → 跳跃、发射、摆荡连续衔接 → 应对更远跨越及不稳定结点 → 及时攀上藤蔓 → 脱离追击路线。
  • 状态改变： 熟悉的动作被放进短决策时间环境，最后由持续威胁转为明确安全。
  • 引导与压力： 前进路线、可抓结点与攀爬出口承担引导；敌人距离和屏幕晃动叠加压力。
  • 失败： 被抓住、落水或动作失误后被追上，具体判定待实测。
  • 设计作用： 主要考动作提取速度和稳定性，并非重新教一种工具。

原记录描述前三组相似“跳跃—套索—摆荡”，随后更长距离，再接终点攀爬。可以据此分析为“建立动作节拍 → 增加变化 → 最后收束”，但不能在没有距离与时间对照的情况下认定每组一定严格递增。

不稳定结点【原记录＋分析】： 脑图称一处高结点抓住即掉落。其功能可解释为限制长期停留、维持追逐流动；“开发者专门为了防止躲避而设置”没有原始开发资料支持，降为分析。

结尾反馈： 敌人坠落、叫声、角色爬到安全位置共同确认追逐终止。视觉结束不等于证实动物死亡，也不需要增加这一剧情结论。

大型综合空间谜题

追逐后的放松来自思考时间变多，空间问题本身依然复杂。

认知高操作中即时威胁较低
B07-P01

多层洞穴的出口与收集支线

体验边界： 追逐后进入可停下来观察的多层空间 → 调整道具与路线 → 从高处出洞。

主线局面： 出口高度不能直接到达，木桶等物体可以改变落脚条件；路线受毛线长度、台阶高度、可推行地形和上方空间约束。

主线解法链： 识别出口与缺失落脚条件 → 移动木桶到垫脚位置 → 利用层层跳跃与连接点向上 → 离开洞穴。本次图示确认木桶被拉到下层后向左推，绿色标出的台阶约束其移动范围。

C04 可选链： 发现纽扣目标 → 寻找较隐蔽的树枝牵拉点 → 使石头落下 → 系结搭出运输路径 → 把石头送到垫脚位置 → 取得纽扣 → 返回主线并处理多余系结。

为何仍保留一个 P： 主线与收集链共享同一个空间、道具关系和毛线预算，原脑图也按整体空间问题划分。为了便于复盘，本文在 P 内区分两条链，不把“拉石头、推木桶、打结”各自当作一题。

补图确认的错误路线： 沿左侧向上、再经过顶部的绕行方案会因毛线长度不足而失败。玩家须在中层调整木桶位置、绕过局部高度限制，重新建立有效向上路线。

状态与约束分析：

约束 玩家遇到的实际问题 分析价值
跳跃高度 有出口却不能直接上去 引向垫脚物体
物体与地形 道具不能随意穿过台阶或窄处 促使玩家规划运输路线
毛线长度 已走路线与系结占用可用长度 把之前做过的连接也变为解题变量
上方净空 有垫脚物也不一定处处能跳 排除部分看似可行的组合
多层可见性 看见目标却看不到完整操作链 要求玩家连接分散的信息

【资料补充】完成额外连接后，解开该区域不再需要的结能帮助避免后续毛线不足。不能只写“毛线短，所以路走错了”，还要考虑已留下的结。TrueAchievements：迷宫后的解结

视听与补给： 原记录为洞穴主题，解谜前后各有补给／存档。地下空间的安静让注意力转回构造关系，但“完全安全”不成立。

动态环境机关组合

鸟先展示因果，玩家再用毛线复现；环境先成为危险，再成为通路。

认知中操作中即时威胁中

体验边界： 离开洞穴回到林地 → 配重改变树枝 → 树间移动与塑料袋 → 木料释放 → 渡水抵达终点前。

B08-P01

利用配重改变树枝形态

  • 受阻局面： 树枝原有姿态不足以构成后续通路。
  • 原记录演示： 鸟落在树枝上使其下弯，提前展示重量会改变形态。
  • 解法核心【补图确认】： 将圆柱重物搬运至下层，与树枝建立毛线连接 → 向左拖动重物产生牵拉 → 树枝弯下，形成向右上通行的路线。用户提供了鸟压枝、鸟飞走后树枝回升、玩家解法成功三张状态图。
  • 状态改变： 重物的位置变化转化为树枝姿态变化，间接改变角色路线。
  • 失败： 落水；如果重物未先连接便落入水中，恢复方式待核验。
  • 设计作用： 从观察外部演示，到用物体重建类似因果。

【资料补充与修订】攻略对物体称呼不统一，出现罐状物、线轴等，因此暂用“圆柱重物”。攻略记有重物落入水中的解法，但用户最新图示为下层向左拖动重物牵弯树枝，正文以用户所示路线为准，不把入水列为必需步骤。Gamepressure：出洞后的配重机关

B08-P02

树间移动与塑料袋滑翔

  • 受阻局面： 树枝与水域之间存在需要多次移动及特殊载体才能跨越的间隔。
  • 解决过程： 树间跳跃与摆荡 → 接近提前可见的塑料袋 → 套取并借其滑翔 → 到达对岸。
  • 状态改变： 移动方式从固定支点摆荡转向借助环境载体越过较大间隔。
  • 引导： 塑料袋预先进入视野，形成短期目标。
  • 操作【你已确认】： 滑翔时需要持续按住“发射毛线”，不能左右控制方向。具体松开后的判定未确认，不套用鱼船规则。
  • 风险【原记录】： 未到岸而落水；不把本段描述成通过左右操纵修正落点的考试。
  • 设计作用： 在熟悉移动中插入一次明显不同的运动体验，为末段增加变化。
B08-P03

释放木料、避险与路径生成

  • 受阻局面： 前方水域难以直接通过，储木设施内的木料可以改变局面。
  • 解决过程： 打开储木门 → 木料滚出 → 迅速转移到上方树枝等安全点 → 等待动态物体稳定 → 借形成的木料通路过水。
  • 状态改变： 封闭储物空间变为空仓；木料先是威胁，随后成为路线。
  • 引导： 门的可交互点、水边上方结点、木料运动方向共同提供行动信息；玩家能否事先看见安全点需截图确认。
  • 失败： 被木料或门砸中、落水；门的具体伤害行为仍待实机细分。
  • 设计作用： 让“解决谜题”本身触发一小段执行压力，再把危险物转成通行工具。

C05 标记： 木料释放后回看已清空的储木空间取得纽扣。它奖励的是事件后的重新观察，而不是首次进入空间时就能完成的搜索。离开该处后还能否返回、是否存在不可逆边界，留空。

视听与补给： 原记录为出洞时洞穴主题切回山林主题，开阔感带来释放；各短谜题后均有补给／存档记录。末段仍有动态危险，所以不能将 B08 概括为无挑战的奖励走廊。
